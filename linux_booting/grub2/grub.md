# 부트로터가 하는 일

## 1. 자기 자신 완성
**동작(레거시):**
 1. <boot.img>가 부트 갭의 첫 섹터를 읽음
 2. <diskboot.img>가 갭의 나머지를 읽음
 3. <lzma_decompress.img>가 압축 해제
 4. <kernel.img>와 모듈이 메모리 전개

**동작(UEFI):** 1. 해당 과정 x (.efi 파일을 읽고 실행시키기 때문)

## 2. 설정 파일 읽기
**동작:**
 1. prefix 값이 /boot/grub의 위치 파악
 2. grub.cfg 읽기

**이유:**
 1. grub가 ext4 파일 시스템의 드라이버 코드 보유


## 3. 메뉴 표시와 대기
**동작:**
 1. 타임아웃 동안 대기
 2. OS 선택
 3. 커널 버전 선택
 4. 복구 모두 진입

## 4. 커널과 initramfs 적재
**동작:**
 1. linux로 vmlinuz를 메모리 적재
 2. initrd로 initramfs를 메모리 적재

## 5. 커널 커멘드 라인 전달
**동작:**
 1. 루트 파일시스템의 uuid를 넘겨줌
 2. 읽기 전용으로 마운트 후 검사
 3. 검사가 끝나면 rw로 재마운트

## 6. 제어권 이양
 1. 커널모드로 진입
